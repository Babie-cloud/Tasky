# Tasky

Tasky is a lightweight, collaborative Kanban project management application built with Angular and Node.js (Express & MongoDB).

## Features

- **Board Management:** Create, update, and organize workspace boards.
- **Kanban Columns:** Organize tasks into customizable workflow columns (*To Do*, *In Progress*, *Done*).
- **Task Cards:** Drag-and-drop task management, due dates, and assignees.
- **Collaboration:** Member invitations with role-based permissions (Admin, Member, Observer).
- **Authentication:** Secure login and registration with JWT and Google OAuth.

## Tech Stack

- **Frontend:** Angular, RxJS, Bootstrap, Angular CDK (Drag & Drop)
- **Backend:** Node.js, Express, MongoDB, Mongoose, JWT
