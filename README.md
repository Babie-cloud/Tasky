# Tasky 
Tasky est un gestionnaire de tâches collaboratif basé sur un flux Kanban. Contrairement aux outils classiques, Tasky sépare strictement le **statut** (la liste/colonne) et la **catégorie** (le type de travail), permettant une organisation fluide sans perdre les labels.

## Stack Technique
- **Frontend :** Angular (Interface utilisateur)
- **Backend :** Node.js / Express / MongoDB (API REST sécurisée)
- **Documentation :** Astro Starlight (Site de doc) & Swagger / OpenAPI (Référence API)

## Documentation
- **Guides & Installation :** [Lancer le site de documentation localement](http://localhost:4321) (depuis le dossier `tasky-docs` avec `npm run dev`)
- **API Reference (Swagger) :** Accessible sur `http://localhost:3000/api-docs` lorsque le backend tourne.
