Ce guide vous accompagne pas à pas pour configurer l'intégralité de l'écosystème Tasky sur votre machine.

## Prérequis techniques

Avant de commencer, assurez-vous d'avoir installé :
- **Node.js** (v18 ou supérieur)
- **MongoDB** (en local ou via un cluster MongoDB Atlas)
- **Git**

---

## 1. Clonage du dépôt

Clonez le projet principal sur votre machine :

git clone [https://github.com/Babie-cloud/Tasky.git](https://github.com/Babie-cloud/Tasky)
cd Tasky
