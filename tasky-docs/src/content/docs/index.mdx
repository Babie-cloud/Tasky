## Pourquoi Tasky ?

<CardGrid stagger>
  <Card title="Architecture à Double Axe" icon="seti:config">
    Fini les compromis. Les listes gèrent l'avancement (**À faire**, **En cours**, **Terminé**) tandis que les catégories gèrent la nature de la tâche (Bug, Design, Feature).
  </Card>
  <Card title="Sécurité et Rôles" icon="approve-check">
    Un système granulaire basé sur des rôles stricts (**Propriétaire**, **Administrateur**, **Membre**, **Observateur**) pour sécuriser chaque espace de travail.
  </Card>
  <Card title="API Prête pour les Devs" icon="laptop">
    Une documentation interactive moderne de type 3 colonnes pour tester et intégrer les endpoints en un clin d'œil.
  </Card>
  <Card title="Open Source & Moderne" icon="open-book">
    Un stack performant bâti sur Angular pour le front-end et Node.js/Express pour le back-end.
  </Card>
</CardGrid>
